- 🔭 최근에는 **AI 연동 웹 서비스**(Plan-AI)와 **자동화 도구**(CGV Watcher, Pixel Watch)를 함께 굴리고 있습니다.
- 📱 **iOS(SwiftUI/SwiftData)** 로 실사용 가능한 유틸리티 앱을 직접 기획부터 배포까지 진행합니다.
- 🌐 **React + FastAPI**, **Spring Boot** 두 축으로 풀스택 웹 서비스를 만들어봤습니다.
- 🎮 여유 시간에는 **Unity/C#**로 게임 프로토타입을 만들며 물리 엔진을 가지고 놉니다.
- 🤝 팀 프로젝트(dmu_sound)에서는 백엔드/프론트엔드 협업과 API 설계를 경험했습니다.
