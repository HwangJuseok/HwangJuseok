## 👋 소개

- 📱 **iOS(SwiftUI · SwiftData · WidgetKit)** 로 실사용 가능한 유틸리티 앱을 기획부터 배포까지 직접 진행합니다.
- 🌐 **React + FastAPI**, **Spring Boot** 두 축으로 풀스택 웹 서비스를 만듭니다.
- 🤖 **Gemini API**를 활용해 자연어 요청을 구조화된 데이터로 변환하는 AI 연동 로직을 설계합니다.
- ⚙️ Python 기반 **화면 감지·이미지 매칭 자동화 도구**로 반복적인 새로고침·모니터링 작업을 대신합니다.
- 🎮 여유 시간엔 **Unity/C#**로 게임 프로토타입을 만들며 물리 엔진을 가지고 놉니다.
- 🤝 팀 프로젝트(dmu_sound)에서 백엔드·프론트엔드 협업과 API 설계를 경험했습니다.
- 📝 코드만큼 **README**를 진지하게 씁니다 — Overview, Tech Stack, 상세 로직, Troubleshooting까지 남겨서 나중에 봐도 바로 이해되게 만드는 걸 원칙으로 합니다.
